Short Project Summaries

Reservoir Infrastructure for Threat Analysis (RITA)

RITA is a demo meant to represent a pumped-energy storage system. There is a lower tank meant to represent a body of water, and upper tank where that water is pumped, and a second lower tank depicting a residential area. This demo is a part of RIOT labs outreach program to teach people about the possible effects of cyber-attacks on infrastructure. In this project, I mapped out the wiring diagrams, wired and installed the components in the pelican case, assisted in building HMI components, as well as designing attack vectors.

Implementing GRUs on AMD Ryzen AI NPU for FLAIR Network-Security Model

FLAIR is a network-traffic anomaly detection model build by RIOT lab. It learns what normal traffic looks like and flags windows that it cannot accurately reconstruct as suspicious. Because it only needs to train on normal behavior, it is useful for IoT and industrial network systems where collecting realistic attack data is difficult or unsafe. The Ryzen AI NPU has a unique tile-architecutre that is designed to speed up neural-network workloads by keeping data close to the compute units and running repeated math operations in parallel. Unfortunately, when trying to run FLAIR on the NPU, most GRU operation were delegated back to the main CPU processor. This is because the tile-architecture isn't designed for RNNs (Recurrent Neural Networks), which are more complicated to parallelize. To get FLAIR running on the NPU, a teammate and I wrote custom encoder and decoder kernels, then used AMD's IRON API to map the computation, memory buffers, and data movement onto the NPU tiles. The host CPU prepares the input windows and launches the NPU work, while the NPU processes the batched GRU inference and sends the results back to the CPU for scoring.

Automated Z-Stage and Powder Bed for Powder Bed Fusion 3D Printer

For this Capstone project, I worked as part of a six-person team to updgrade a laboratory powder bed fusion (PBF) 3D printer by automating its manually opperated Z-axis. The project involved redesigning the powder bed and Z-stage, integrating a stepper motor and embedded control system for precise movement, and developing a user interface for system operation.
